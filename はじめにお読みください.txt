ちゃわん娘アルバム　使い方
===========================

【最初の1回だけ】
1. このZIPを解凍します。
2. 解凍した「chawan-album-site」フォルダの中身を、すでに使っている
   GitHubの「yosakoi-web / yosakoialbum」のリポジトリの一番上にアップロードします。
   ※ZIPファイルをそのまま置くのではなく、解凍した中身を置いてください。
   ※「chawan-album-site」という親フォルダごと置かず、中の index.html が
     リポジトリの一番上に見えるようにしてください。
3. 写真は photos の中の好きなフォルダに入れます。

【以後やること】
写真を追加するときは、GitHubのリポジトリで photos/イベント名/ に写真を追加するだけ。
GitHubの画面で「Add file → Upload files」を使えます。
新しいイベントを作る場合も、photos に新しい名前のフォルダを追加するだけ。
HTML・CSS・JSを編集する必要はありません。コマンドもワークフローも不要です。

【サイトのURL】
https://yosakoi-web.github.io/yosakoialbum/
※このサイトでGitHub Pagesがすでに公開されている前提です。
  公開がまだなら、GitHubの Settings → Pages → Deploy from a branch →
  main（または公開に使うブランチ） / (root) を選ぶ初回設定だけ必要です。

【合言葉】
ちゃわん娘
写真を閲覧する人がサイトで入力します。
写真をGitHubに追加するあなたは、今までどおりGitHubへログインして作業します。

【ダウンロード】
・写真をタップしてプレビュー → 「この写真をダウンロード」
・アルバムカードやアルバム上部の「まとめて保存」→
  「写真を1枚ずつ保存」または「ZIPでまとめて保存」を選択
・スマホでは連続ダウンロードがブロックされることがあります。
  その場合はZIPを使ってください。ZIP内の写真は1枚ずつの元画像です。
・スマホでは写真が「写真」アプリではなく「ファイル」に保存されることがあります。

【写真形式とアップロード】
JPG/JPEG、PNG、WebP、GIF、AVIFに対応しています。
スマホとの相性を考えるとJPGがおすすめです。HEICは表示対象外です。
GitHubのブラウザからのアップロードは、1ファイル25MiBまで、1回100ファイルまで。
枚数が多いときは分けてアップロードできます。

【大事：パスワードについて】
GitHub Pagesは公開型の静的サイトのため、この合言葉は
「アルバムの画面を簡易的にロックするもの」です。
写真のURLを知っている人やソースコードを調べる人を防ぐ安全な認証ではありません。
プライベート・機密性の高い写真は公開リポジトリにアップロードしないでください。

【動作について】
写真一覧はGitHubの公開APIから自動で読み込みます（公開リポジトリが必要）。
最初のアップロード直後はGitHub Pagesの反映まで少し時間がかかる場合があります。
ローカルで index.html を直接開くと写真のプレビューができないことがあります。
実際の確認は公開URLで行ってください。
外部ライブラリの追加、Python、Actions、ビルド作業は不要です。
